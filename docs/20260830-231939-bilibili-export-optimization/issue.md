# B站视频导出优化需求

## 原始诉求

优化 Phira Render 的视频导出，使高动态音游画面更适合上传 B站，并让输出参数更明确、稳定、标准。

## 已确认事实

- 当前本地输出为 1920×1080、CFR 60fps、H.264 Main、yuv420p、逐行扫描，未发现帧丢失或时间戳错乱。
- 默认视频码率为 7 Mbps；示例文件实际视频码率约 7.1 Mbps。
- B站普通 1080P 会将示例稿件转为约 878 kbps AV1、30fps；1080P 60帧档位在该视频页面标记为大会员画质。
- 当前 FFmpeg 参数未显式声明输出 CFR、BT.709、GOP、faststart。
- 硬件编码路径对 rawvideo 输入附带了无效的 `-hwaccel_output_format cuda`。
- 码率填写 `0` 时，项目已有 NVENC CQ18 / x264 CRF18 质量模式。

## 优化目标

- 保持渲染帧内容、时间轴和音画同步不变。
- 输出明确的 CFR、BT.709、yuv420p、逐行 MP4。
- 使用适合平台转码和拖动定位的固定 GOP。
- 改善高动态细线画面上传前的源质量。
- 不承诺绕过 B站普通 1080P 的 30fps 平台限制。

## 已确认范围

- 新增“B站高质量”预设并设为新默认。
- 保留旧版 7M 内置预设作为回退。
- 同时优化底层 FFmpeg 输出参数。

## 成功标准

- 新导出文件被识别为 1920×1080、CFR 60fps、H.264 High、BT.709、yuv420p。
- GOP 约 2 秒，MP4 启用 faststart。
- 输出总帧数等于 `ceil(时长 × fps)`，无异常 VFR。
- DEINOS/Riven 开场黑帧、跳变与截图回归继续通过。
